# Howzatt! Cricket Scorekeeper 🏏

**A simple and interactive cricket scorekeeping web app built using HTML, CSS, and JavaScript.**

---

## Features ✨

- Keep track of runs, wickets, overs, and balls.  
- Update scores in real-time as the game progresses.  
- Track individual player scores and extras.  
- User-friendly interface with responsive design.
- Prompting Player names from user given input  
- Lightweight and easy to use for casual games.
